# Backend SRI Files

Este proyecto usa Maven y Spring Boot.

## Importación recomendada

Abre esta carpeta directamente en VS Code para que el Java Language Server detecte el proyecto correctamente:

- backend/

No abras solo la raíz del repositorio si quieres evitar errores de classpath.

## Comandos útiles

```bash
./mvnw clean compile
./mvnw test
./mvnw spring-boot:run
```
